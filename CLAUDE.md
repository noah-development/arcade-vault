## Project

Arcade Vault — an online platform for playing games and competing for high scores. Currently an unmodified `create-next-app` scaffold: `app/layout.tsx` and `app/page.tsx` are still the generated defaults, and no domain code exists yet.

The project follows spec-driven development using the `/spec` and `/spec-impl` skills from [Klerith/fernando-skills](https://github.com/Klerith/fernando-skills), installed with:

```bash
npx skills@latest add Klerith/fernando-skills
```

Write the spec before the implementation, and implement against the spec.

## Stack notes

- **Next.js 16.3.3 / React 19.2.8, App Router.** Next 16 has breaking changes vs. older App Router code — follow the `@AGENTS.md` rule above and read `node_modules/next/dist/docs/` (`01-app/03-api-reference/`) before writing framework code rather than relying on Next 13–15 habits.
- **Route types are generated globals.** `layout.tsx` types its props as `LayoutProps<"/">` — use the generated `LayoutProps<Route>` / `PageProps<Route>` globals (backed by `.next/types`) instead of hand-writing `{ params, searchParams }` types. These only exist after a `dev`/`build` has generated them.
- **Tailwind v4, CSS-first.** There is no `tailwind.config.*`. Theme tokens live in `app/globals.css` under `@import "tailwindcss"` + `@theme inline`; add design tokens there, not in a JS config. Wired through PostCSS via `@tailwindcss/postcss`.
- **Import alias:** `@/*` resolves to the repo root (so `@/app/...`), not to a `src/` directory.
- `AGENTS.md` is regenerated by `next dev`; commit it alongside your changes rather than reverting it.
